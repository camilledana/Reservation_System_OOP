# Hotel Management System

A Java-based hotel management application for room reservations, customer tracking, and booking validation. Built to practice object-oriented design and real-world business logic.

## Why This Project Exists

Managing hotel rooms, customers, and reservations involves overlapping rules: rooms can only be booked if available, customers need records, and reservations must be validated against dates and capacity. I built this project to model those rules cleanly using object-oriented principles rather than hard-coded logic.

## Features

- Room management (add, update, view availability)
- Customer tracking (create and look up customer records)
- Reservation handling with date and availability validation
- Input validation and error handling
- Clean separation between data models and business logic

## Tech Stack

- **Language:** Java
- **Build tool:** Maven (or Gradle)
- **Storage:** In-memory / file-based (or MySQL, if used)
- **Testing:** JUnit
